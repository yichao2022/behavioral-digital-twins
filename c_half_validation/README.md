# c-half OOD Validation Data

This directory contains the **c-half out-of-design validation data** used for the
MiroThinker-1.7-mini OOD metrics reported in Figure 1 and the discussion of
MVR-Wait violations in Section~\ref{sec:why_not_dce}.

## Why a separate data source?

The main paper analysis uses two data sources:

| Source | Location | Used for |
|---|---|---|
| Pre-registered 12-scenario OOD | `results/out_of_design_parsed_probabilities.csv` | Qwen2.5-72B and DeepSeek V3 OOD metrics |
| c-half OOD (200 respondents × 38 scenarios) | `c_half_validation/MiroThinker-1.7-mini_n200_n40.csv` (this dir) | MiroThinker-1.7-mini OOD metrics |

The **MiroThinker-1.7-mini** open-source model is not hosted on the OpenRouter
inference API used for the pre-registered 12-scenario OOD study. To evaluate
MiroThinker on the same out-of-design *narrative extension* task, we ran a
**c-half validation study** using a role-played respondent design (200
respondent personas, each making choices on 38 of the 40 paired OOD scenarios;
the 2 unmatched scenarios per respondent were dropped due to randomization
buffer boundaries). This produces 7,600 nominal choice rows per model, of which
62.5% (MiroThinker) parse successfully. This parse rate is *not* the
"monotonicity violation rate" reported in Figure 1 and Section~\ref{sec:why_not_dce};
that figure (5/6 paired groups, 83.3%) refers to the proportion of
**wait-time-monotonicity violations** in the parsed subset, which is a
separate metric computed in `scripts/plot_figure1_3model.py`.

## Files

- `MiroThinker-1.7-mini_n200_n40.csv` — Raw LLM outputs for MiroThinker-1.7-mini
  on the c-half validation set (8,000 rows; 6.4 MB). Columns:
  `decision`, `probability_0_1`, `reasoning`, `parse_success`, `raw_response`,
  `model`, `repeat`, `scenario_id`, `wait_time`, `efficacy`, `side_effects`,
  `side_effects_text`, `extra_policy_description`,
  `expected_wait_order_group`, `respondent_id`, `latency_s`.

## Reproducing MiroThinker OOD metrics

```bash
# From repo root
python3 scripts/plot_figure1_3model.py
# This reads c_half_validation/MiroThinker-1.7-mini_n200_n40.csv
# (alongside results/out_of_design_parsed_probabilities.csv for Qwen/V3)
# and writes figures/figure_1_ood_performance.png
```

The plot script's `V1` path defaults to this directory (relative to the script
location), so no environment variables are required for the MiroThinker panel.
Qwen2.5-72B and DeepSeek V3 panels are read from
`results/out_of_design_parsed_probabilities.csv` (a 240-row file generated by
`scripts/out_of_design_stress_test.py`).

## Provenance

Generated 2026-08-10 as part of a manuscript revision stress test. The full
c-half experiment log (covering Qwen2.5-7B, DeepSeek V4-Flash, and
MiroThinker-1.7-mini) is available in the supplementary archive; only the
MiroThinker subset is committed here because it is the only one used in
Figure 1.
